# 浏览器端 AK 获取与排查

百度地图 JSAPI 必须使用浏览器端 AK。不要使用服务端或移动端 AK，也不要在交付代码中放入 `YOUR_AK`、遮掩值或猜测值。

## 获取顺序

1. 优先使用环境变量 `BMAP_JSAPI_KEY` 中的有效浏览器端 AK。
2. 环境变量缺失时，使用同 Agent Plugin 的 `bmap-cli` skill。由它完成 CLI 自举和登录，执行 `ak list`，并按应用类型、服务范围、状态和 Referer 白名单选择唯一匹配项。
3. 没有合适 AK 时，由 `bmap-cli` 说明拟创建的浏览器端应用与白名单风险；取得用户明确同意后创建，再重新查询并使用当前结果。
4. 仅当 `bmap-cli` skill 不可用时，才引导用户前往[百度地图开放平台控制台](https://lbsyun.baidu.com/apiconsole/key)创建浏览器端 AK，并设置：

```bash
export BMAP_JSAPI_KEY="<浏览器端 AK>"
```

## 白名单

- 生产项目使用准确的 Referer 域名白名单。
- `*` 仅适用于本地 demo 或受控测试。使用前必须说明它会扩大 AK 暴露面并带来配额滥用风险。
- 现有 AK 的白名单与页面来源不匹配时，不要把它强行写入代码；改用匹配的 AK 或经用户同意创建新应用。

## 故障排查

地图未加载或浏览器控制台报告鉴权错误时，依次检查：

1. AK 是否确为浏览器端类型。
2. script URL 中的 `ak` 是否完整且没有多余空格。
3. Referer 白名单是否覆盖当前页面来源。
4. AK 状态、服务范围与配额是否正常。

需要查看或变更账户资源时转到 `bmap-cli`，不要在本 reference 中复制一套控制台管理流程。
